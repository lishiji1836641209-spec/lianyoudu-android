# 练有度

练有度是一款干净简洁的运动健康软件。看图练动作，记下今天用了哪些器械、吃了哪些食物。连上支持心率广播的设备，还能记录运动时的心率。每天的记录，都能在手机里翻看。

[下载安卓版 APK](https://github.com/lishiji1836641209-spec/lianyoudu-android/releases/latest)

源码和安装包仅供非商业使用，禁止商用。详见[使用许可](LICENSE)。

## 从源码运行

用 Android Studio 打开仓库，连接安卓手机，选择 `app`，点击运行。

## 素材来源

食物营养参考数据来自 [USDA FoodData Central](https://fdc.nal.usda.gov/)。Gradle Wrapper 沿用其随附许可。
